# Space Pong – Group 4
A complete Pong-style game implemented entirely in MIPS assembly using the MARS Bitmap Display.

## Features
- Pixel-art graphics (spaceships, asteroid ball, starfield)
- Menu system and winner screen
- Physics engine with ball speed control
- AI opponent with random mistakes
- Two game modes (single player and multiplayer)
